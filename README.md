# AI Coach Agent using n8n

An AI-powered personal learning assistant built using **n8n Workflow Automation** and **AI Agents**. The agent automates study planning by reading learning roadmaps from Gmail, generating personalized study schedules, managing Google Calendar events, creating notes in Google Docs, sending reminder emails, and answering follow-up questions using LLMs.

## 🚀 Features

- 📧 Reads learning roadmaps from Gmail
- 🤖 AI-powered study plan generation
- 📅 Automatically creates Google Calendar events
- 📝 Creates and updates notes in Google Docs
- ✉️ Sends reminder and follow-up emails
- 💬 Answers learning-related questions using AI
- 🔄 End-to-end workflow automation with n8n

## 🛠️ Tech Stack

- n8n Workflow Automation
- AI Agents
- OpenAI / Gemini LLM
- Prompt Engineering
- Gmail

- Google Drive

- Webhooks

## 📂 Workflow Overview

1. Read learning roadmap from Gmail
2. Analyze roadmap using an AI Agent
3. Generate a personalized study schedule
4. Create calendar events automatically
5. Create and update notes in Google Docs
6. Send reminder emails
7. Answer follow-up questions using AI

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Coach-Agent-n8n.git
```

2. Import the `AI_Coach_Agent.json` workflow into n8n.

3. Configure your credentials:

- Gmail
- Google Calendar
- Google Docs
- OpenAI/Gemini API Key

4. Execute the workflow.
